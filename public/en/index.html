// 04 — SECURITY

Built to be trusted with your keys

Linking your Roblox account means handing over an Open Cloud key. Here is exactly what happens to it.

  • Encrypted at rest

    Every key is stored with AES-256-GCM authenticated encryption — ciphertext, IV and auth tag. Never plaintext.

  • Never sent back, never logged

    No endpoint returns your key or its ciphertext. It only leaves our servers inside a request header to Roblox.

  • Only the scopes we actually use

    We ask for read, create and update on your DataStore. We never ask for delete.

  • Unlinking deletes it

    Unlink removes the stored key from our database outright — an actual delete, not a flag.
