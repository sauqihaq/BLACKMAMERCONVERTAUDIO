// 04 — KEAMANAN

Dibangun untuk dipercaya memegang API key kamu

Menghubungkan akun Roblox berarti menyerahkan Open Cloud key. Ini persisnya yang terjadi pada key itu.

  • Terenkripsi saat disimpan

    Setiap key disimpan dengan enkripsi terautentikasi AES-256-GCM — ciphertext, IV, dan auth tag. Tidak pernah plaintext.

  • Tidak pernah dikirim balik, tidak pernah dicatat

    Tidak ada endpoint yang mengembalikan key kamu atau ciphertext-nya. Key hanya keluar dari server kami di dalam header permintaan ke Roblox.

  • Hanya scope yang benar-benar kami pakai

    Kami minta read, create, dan update untuk DataStore kamu. Kami tidak pernah minta delete.

  • Unlink menghapusnya

    Unlink menghapus key tersimpan dari database kami sepenuhnya — benar-benar dihapus, bukan sekadar ditandai.
